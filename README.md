## 📌 Project Overview
**ITXStudie** is a study-tracking application designed to help users stay on track through customizable timers, categories, and deep data tracking. Inspired by professional focus apps, this project serves as a comprehensive journey into Fullstack Development and Software Architecture.

The long-term vision incorporates AI-driven recommendations and cognitive science principles to provide personalized study guidance and workflow insights.

---

## 🏗️ Architecture

- **Frontend:** Next.js (React), TailwindCSS, Zustand
- **Backend:** NestJS (Node.js framework)
- **Database:** PostgreSQL with Prisma ORM
- **Future ML/Analytics:** Python, Pandas, FastAPI
